# Warrior Tank HUD

전사 캐릭터의 체력·분노와 방패 막기, 복수, 도발, 천둥벼락 상태를 화면 중앙 아래에 표시하는 와우 포에버 베타용 애드온 초안입니다.

## 베타 클라이언트 확인 필요

현재 작업 환경에는 와우 포에버 베타 클라이언트가 없습니다. `WarriorTankHUD.toc`의 `Interface: 0`은 **설치 전 교체해야 하는 명시적 자리표시자**이며, 지금 상태로 게임에서 로드된다고 주장할 수 없습니다. 주문 ID와 쿨다운·사용 가능 API도 확인 전입니다.

게임 PC에서 다음 정보를 확인해야 합니다.

1. 베타 클라이언트에 포함된 기본 애드온의 `.toc` 파일에서 `## Interface` 값을 확인합니다.
2. 게임 내 주문책에 있는 방패 막기, 복수, 도발, 천둥벼락의 주문 ID를 확인합니다. 각 기술이 여러 등급이면 현재 캐릭터가 사용하는 등급을 기록합니다.
3. 클라이언트의 UI 소스나 게임 내 개발 도구로 주문 쿨다운·사용 가능 여부 API의 이름과 반환 형태를 확인합니다. 베타 패치 번호도 함께 기록합니다.
4. 확인된 `Interface` 값을 TOC의 `0` 대신 넣습니다. `Core.lua` 맨 아래 `spellIds` 테이블의 `nil` 네 곳을 각각 확인한 정수 주문 ID로 교체합니다. 이 작업 전에는 네 기술이 비활성으로 표시됩니다.
5. `/reload`로 로드 오류를 확인합니다. `/wthud reset`은 HUD 위치를 기본값으로 되돌립니다.

## 설치 후 게임 내 검증

`WarriorTankHUD` 폴더를 베타 클라이언트의 `Interface/AddOns` 아래에 복사합니다. 전사로 접속하여 체력·분노 변동, 네 기술의 사용 가능 여부와 쿨다운, 복수 활성화, 이동 후 재접속 위치 유지, `/wthud reset`, 다른 직업에서 HUD 숨김을 확인합니다. 기본 UI나 다른 애드온과 HUD가 겹치면 위치를 옮깁니다.

베타 패치에 따라 기술 ID 또는 전투 중 API가 바뀔 수 있습니다. 확인할 수 없는 기술 상태는 사용 가능으로 추측하지 않고 비활성으로 표시합니다.

## 로컬 검증

시스템 Lua 공유 라이브러리가 있는 환경에서 `python tests/run_lua.py tests/state.lua`와 `python tests/run_lua.py tests/view.lua`로 상태 모델과 화면 로직을 검증합니다. 이 테스트는 Lua 5.4를 사용하므로 베타 클라이언트의 Lua 및 UI API와 완전히 같다는 뜻은 아닙니다.
