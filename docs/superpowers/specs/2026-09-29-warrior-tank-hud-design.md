# 전사 탱킹 HUD 설계

## 목적과 범위

와우 포에버 베타에서 전사 탱킹 중 자주 확인하는 체력, 분노, 방패 막기, 복수, 도발, 천둥벼락을 캐릭터 아래 한곳에서 확인한다. 첫 버전은 독립형 애드온으로 만들며, 어그로 경고, 대상 차단, 전투 로그 분석, 키 바인딩 보조 기능은 포함하지 않는다.

## 화면과 동작

- HUD는 화면 중앙의 캐릭터 아래에 고정된 위치에서 항상 보인다. 월드 속 캐릭터를 따라 움직이는 프레임은 아니다.
- 전사 캐릭터에게만 HUD를 표시한다. 전사에게는 비전투 중에도 표시한다.
- 체력과 분노를 막대와 현재 수치로 표시한다.
- 방패 막기, 도발, 천둥벼락은 각각 기술 아이콘, 남은 쿨다운, 게임 API가 제공하는 사용 가능 여부를 표시한다. 사용할 수 있으면 밝게, 사용할 수 없으면 어둡게 표시한다. 천둥벼락으로 대상에게 걸린 효과의 남은 시간은 표시하지 않는다. 대상과의 거리 등 API로 확인할 수 없는 조건까지 사용 가능하다고 추측하지 않는다.
- 복수는 기술 아이콘으로 표시하고 사용 가능할 때 강조한다. 사용 불가능한 이유를 세분화하여 판정하거나 권장 행동을 자동으로 결정하지 않는다.
- HUD는 마우스로 이동할 수 있고, 옮긴 위치는 캐릭터의 설정에 저장한다. 초기화 명령으로 기본 위치에 복귀할 수 있다.
- 기술을 배우지 않았거나 해당 기술의 상태를 읽을 수 없으면 사용 가능 상태를 추측하지 않고 비활성으로 표시한다.

## 구성과 데이터 흐름

애드온 폴더에 TOC 메타데이터와 Lua 파일을 둔다. 화면 모듈은 막대와 아이콘을 그리며, 상태 모듈은 게임 API에서 플레이어 체력·분노·기술 쿨다운 및 사용 가능 여부를 읽는다. 이벤트가 발생하면 관련 상태를 다시 읽고 화면을 갱신한다. 쿨다운 숫자에 필요한 경우에만 짧은 주기 갱신을 사용한다. 위치 저장은 게임의 SavedVariables를 이용한다.

기술은 이름 문자열보다 확인된 주문 ID로 식별한다. 와우 포에버 베타의 기술 ID, TOC의 `Interface` 값, 이벤트 및 전투 중 API 제한은 실제 설치된 클라이언트에서 확인한 뒤 최종 값을 정한다. 현재 이 값들은 확인되지 않았다. 제한된 값이 확인되면 해당 요소의 비활성 표시와 진단 메시지로 안전하게 처리하며, 허용되지 않은 전투 계산이나 자동 시전은 구현하지 않는다.

## 검증 기준

1. 전사로 로그인하면 HUD가 표시되고 체력과 분노가 게임의 기본 UI 수치와 일치한다.
2. 피해·회복·분노 변화에 따라 막대와 수치가 갱신된다.
3. 방패 막기, 도발, 천둥벼락 사용 후 남은 쿨다운이 표시되고, 종료 시 게임 API의 사용 가능 상태와 HUD 강조 상태가 일치한다.
4. 복수의 게임 내 사용 가능 상태와 HUD 강조 상태가 일치한다.
5. 이동한 위치가 재접속 후 유지되고 초기화 명령으로 기본 위치에 돌아온다.
6. 다른 직업에서는 HUD가 숨겨지고, 기술 미습득, API 반환값 없음, 전투 중 상태에서 오류 없이 처리된다.

실제 와우 포에버 베타 클라이언트에서 위 항목을 검증한다. 로컬 정적 검사만으로는 게임 내 API 동작을 보증할 수 없다. 기본 UI나 다른 HUD 애드온과 위치가 겹치거나, 베타 패치 후 기술 ID·이벤트·API가 바뀌어 표시가 어긋날 수 있다.
